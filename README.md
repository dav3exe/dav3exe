# Tolulope Ogungbemi (Dav3)

Full stack developer in Lagos, Nigeria. I mostly write TypeScript, with React and Next.js on the frontend and Node.js or FastAPI on the backend, on top of PostgreSQL or MongoDB.

I use AI coding agents every day. They help me plan, write and review code, and I test and check everything they produce before it ships. I care about security and keep an eye on Web3.

## Products I've worked on

- **[start.ng](https://start.ng)**: a platform for playing and publishing web games. Team lead during HNG 15; CI and security checks, server-rendered pages, tournaments and the event spotlight. [Frontend repo](https://github.com/startnextgen/startng-fe)
- **[Ziki](https://ziki.dev)**: an issue tracker where AI agents find, fix and review work. Built "Scan again" for Ziki Security. (Private repo)
- **Zedu**: a chat and learning app for schools and training programs. Desktop (Flutter), web (TypeScript) and mobile (React Native) work. [Desktop](https://github.com/zeduchat/zedu-desktop) · [Web](https://github.com/zeduchat/zedu-fe) · [Mobile](https://github.com/Cybertron-HNG/zedu-mobile)
- **[Eventra](https://eventra-client-delta.vercel.app)**: an event ticketing platform. Event creation, organiser onboarding, refunds and disputes. [Repo](https://github.com/Chloetrini/Eventra-Client)
- **[NestFinder](https://nestfinder-real-estate-ljlj.vercel.app)**: a property listing site for people renting or buying homes in Nigeria. The all-properties page and admin pages, frontend and backend. [Repo](https://github.com/Chloetrini/nestfinder-real-estate)
- **[SuperTracker](https://github.com/dav3exe/super-tracker)**: looks at a Solana memecoin and tells you whether its trading looks real and who its biggest holders are.
- **[The Hooded Swordsman](https://github.com/dav3exe/the-hooded-swordsman)**: a dark 3D combat game in three.js.
